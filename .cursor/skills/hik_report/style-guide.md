# 文风细则

## 推荐开篇模板（章首）

1. 本章回答什么问题（一句）
2. 不回答什么 / 前提限定（一句）
3. 后文阅读地图（可选一句）

## 推荐收束模板（章末或节末）

1. 本章得到的可执行判断
2. 该判断对下一章提出的问题
3. 仍开放的缺口（若有）

## 常见句角色（写注解时可用）

| 角色 | 识别线索 | 注解时应点明 |
| --- | --- | --- |
| 定义 | 「是指」「称为」 | 外延边界 |
| 限定 | 「不是…而是…」「尚不能」 | 防误读为终局 |
| 框架 | 「可拆成」「对照」「谱系」 | 后文将复用的尺子 |
| 证据 | 链接、数据、具名案例 | 证据强度与来源类型 |
| 对比 | 「与此不同」「相对」 | 对比轴是什么 |
| 过渡 | 「因此」「下一章」 | 逻辑跳步是否成立 |
| 收束 | 「结论」「总判读」 | 可带走的一句话 |

## 禁忌

- 用空洞排比代替机制（「引领未来」「全面赋能」而无主体与条件）
- 把实验室演示写成产线常态
- 同一概念多名并存（前后不统一）
- 总结时引入原文没有的因果
