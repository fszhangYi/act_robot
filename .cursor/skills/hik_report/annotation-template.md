# 汇报版逐句注解模板

用于 `verbose.md` 或同等交付。主题随原文，不套固定行业故事。

```markdown
# 《文档标题》汇报版详解

## 全书行文思路（短）

用一段话说明：全文要解决的问题 → 分几段推进 → 最终落到什么判断。

## N. 章节标题

### 行文思路

说明本章在论证链上的位置。

### 逐句注解

#### 段落地标（可选）

> **原句：** ……
>
> **注解：** ……（可标注角色：定义/限定/证据/过渡/收束）

（下一段继续）

### 本节小结

一句说明本节推进了什么。
```

## 切句规则

1. 优先按 `。！？` 切分
2. 冒号后若是完整命题，可单独成条
3. 列表项：一条列表 = 一条「原句」单位
4. 表格：先写「表意」，再选关键行注解；全表逐格注解仅在用户明确要求时做

## 质量标准

- 读注解应能在不看论文的情况下做 3 分钟口播
- 每节小结能回答「所以呢？」
- 不把注解写成同义反复（禁止仅复述原句）
